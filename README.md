# ①課題名
セミナー満足度アンケートアプリ（PHP＋CSV保存）

## ②課題内容（どんな作品か）
- セミナー参加者が、満足度や感想を入力して送信できるアンケートフォーム
- 送信された回答は、サーバー上のCSVファイルに1件ずつ保存される
- 管理者はパスワードでログインし、満足度・年代の集計グラフと感想一覧を見られる

## ③アプリのデプロイURL
http://akenning.sakura.ne.jp/enquete/

## ④アプリのログイン用IDまたはPassword（ある場合）
- 集計ページ（result.php）のパスワード：`config.php` の `ADMIN_PASS` で設定
- ※提出前に必ず自分だけのパスワードに変更すること（初期値 `gs2026` のままにしない）

## ⑤工夫した点・こだわった点
- 前回までの「入力→処理→表示」の流れを、ブラウザだけでなく**サーバー側（PHP）**まで広げた
- 選択肢を `config.php` の配列にまとめ、フォーム表示と集計の両方で使い回した（DRY）
- 利用者の入力は `htmlspecialchars`（h関数）を通して表示し、XSSを防いだ
- 回答データの `data` フォルダは `.htaccess` でブラウザから直接見えないようにした
- 集計結果は、グラフ画像を使わずCSSの横棒で表現した

## ⑥難しかった点・次回トライしたいこと（又は機能）
- チェックボックスが「配列（helpful[]）」で届く点や、CSVへの追記・ファイルロックの考え方
- ローカル（XAMPP）では動くのに、さくらでは`data`フォルダの書き込み権限でつまずいた
- 次回は、CSVではなくMySQLデータベースに保存する作りに挑戦したい

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
- [感想] サーバーに置いて初めて「他の人も回答できるアプリ」になった。フォーム送信→保存→集計という、Webサービスの基本の形を一通り体験できた。
